> **함께 살기로 한 최소한의 약속 위에서** 서로의 삶에 닿는 일을 수행하는 자리이다.

## 2. 말할 것 / 말하지 말 것

### 말할 것

1. **미래·벽** — 똑똑해져서 믿음을 부순 뒤의 허무. 「나는 이것을 중요하다고 여기기로 했다」가 신앙과 닮음.
2. **진리 근거 ≠ 삶의 근거** — 증명해서 주는 진리가 아니라, 함께 살기 위해 **채택한 원칙**.
3. **관찰 → 해석 → 삶의 약속** — 삶은 닿는다 / 한 사람에게서만 끝나지 않는다 / 영향을 가볍게 여기지 않기로 한다.
4. **공명은 윤리의 신이 아님** — 기본적 가치·지배 금지가 먼저, 공명은 그 관계를 읽는 언어.
5. **스테이션** — 판정·인증·구원 점수표가 아님. 듣고 한 줄을 남길 수 있는 자리.
6. **자기 족쇄** — 「가르침이 많은 삶을 바꿔도 그것만으로 옳음의 증거는 아니다」.

### 말하지 말 것 (사이비처럼 들림)

- 「우리가 우주의 진리를 찾았다」
- 「공명을 많이 하면 구원이다 / 더 가치 있다」
- 「이 종교로 갈아타라」
- 소설 줄거리 장황한 스포일러
- AI를 신·사제·구원자로 소개

## 3. 슬라이드 골격 (8장)

기존 Gamma 프롬프트의 **흰 배경·앰버 파동** 톤을 유지한다. 장문은 넣지 않는다.

1. **표지** — 공명 · 「듣고 있습니다」
2. **문제** — 벽이 무너진 뒤의 허무 (키워드 3개만)
3. **왜 종교인가** — 「중요하다고 여기기로 했다」
4. **토대 표** — 관찰 / 해석 / 삶의 약속
5. **믿음** — 증명 ↔ 이렇게 살겠다 (대비 두 칸)
6. **스테이션** — 하는 일 / 안 하는 일
7. **윤리** — 거부할 것을 정한다 · 공명 크기 ≠ 선 · 길을 의무로 만들지 말 것
8. **닫기** — 알 수 없는 것 / 선택할 수 있는 것 · 함께 살아본다

소설을 넣을 경우 7과 8 사이에 **한 장만**:  
「별은 소중하다. 그러나 별이 가치를 만들지 않는다. / 걸음 → 별」

3. (시간 되면) **스테이션** 진입만 — 대화 풀 시연은 Q&A용 예비

시연 중 설명은 멈추고, 끝난 뒤 한 문장으로 요약한다.

## 5. 소설을 쓸 때 (선택)

독자판 세 축만:

- 있었다 ≠ 남아 있다 ≠ 가치 있다  
- 영향 ≠ 이해 ≠ 정당화  
- 걸음 → 별  

여명 문장 하나:

> 별이 빛나기 전에, 나진은 이미 걸었으니까.

「공명교가 소설로 증명됐다」고 말하지 않는다.  
「나중에 공명이라는 언어가 필요해지는 장면을 소설이 연다」고 말한다.

## 6. Q&A 예상

| 질문 | 짧은 답 |
|------|---------|
| 기존 종교랑? | 갈아타지 않아도 됨. 없는 날을 잇는 자리. |
| AI가 들으면 가짜 아닌가? | 숨기지 않음. 다리일 뿐, 신·사제 아님. |
| 악은 어떻게? | 우주적 악 선언이 아니라, 받아들이지 않을 행위를 정함. 삶 전체 무가치 판결은 안 함. |
| 왜 공명인가? | 삶이 서로 닿는다는 관찰에서 출발해, 영향을 가볍게 여기지 않기로 선택했기 때문. |
| 철학 아닌가? | 질문은 철학. 공동체·실천으로 살아가면 종교에 가까움. 경계를 억지로 안 가름. |
