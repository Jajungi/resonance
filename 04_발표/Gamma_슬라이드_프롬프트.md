# Gamma용 슬라이드 프롬프트 — 공명(共鳴) 스테이션

사용법: 각 슬라이드에서 **「공통 컨셉」을 먼저 붙인 뒤**, 해당 장의 **슬라이드 프롬프트**를 이어서 붙여 넣는다.

**색·분위기 레퍼런스:** 어두운 배경 + 앰버 동심원 파동의 표지 느낌은 유지하되, **배경만 흰색**으로 뒤집은 버전. 파동·얇은 원호는 같은 앰버/코퍼, 글자는 진한 차콜.

---

## 공통 컨셉 (매 슬라이드 앞에 복사)

```
당신은 대학 교양 「인간과 종교」 조별 계획안 발표용 슬라이드를 만든다.
프로젝트명: 공명(共鳴) 스테이션 — 2035 미래 종교 디자인.
핵심 한 줄: 새 교단이 아니라, 다종교·지역사회가 공유하는 Micro-Care 영적 인프라.
표어: 「듣고 있습니다」 · 「말씀해 주십시오」.

시각·톤 (통일, 절대 지킬 것):
- 분위기: 고요한 경청, 여백, 미니멀·명상적. 숭배·키치·사이비·사이버펑크 감성 금지.
- 배경: 반드시 흰색 또는 매우 옅은 오프화이트 (#FFFFFF~#FAFAF8). 다크/차콜 배경 금지.
- 액센트 색: 따뜻한 앰버·코퍼 오렌지(발광하는 얇은 원호·파동). 참고 — 어두운 슬라이드의 주황 파동을 화이트 위에 올린 느낌.
- 텍스트 색: 본문·제목은 진한 차콜/소프트 블랙. 보조 문구는 미드 그레이. 흰색 글자는 쓰지 말 것(배경이 흰색이므로).
- 그래픽: 얇은 선으로 된 동심원 파동·잔잔한 리플 1개. 과장된 이퀄라이저·네온 글로우 과다·보라 그라데이션 금지.
- 타이포: 제목은 짧고 크게, 본문은 3~5줄 이내. 모던 산세리프. 보고서체 장문 금지.
- 이미지: 슬라이드당 핵심 시각 1개만. 장식 아이콘 다발·콜라주·종교 성물(십자가·불상) 기본 배치 금지.
- 상징: 잔잔한 원형 앰버 파동. 의자는 상징이 아니라 앉을 자리(가구).
- AI: Bridge(매개). 신·사제·구원자로 그리지 말 것.
- 언어: 발표용 짧은 한국어. 「본 기획안은~로 분석된다」식 학술 장문 금지.
- 레이아웃: 아래 「현재 배치」를 존중하되, 흰 여백을 충분히. 새 교리 선전처럼 보이지 말 것.
```

## 슬라이드 01 — 표지

**현재 배치:** 상단 부제, 중앙 큰 제목(공명(共鳴) 스테이션), 하단 조 정보. 이미지 다수(장식).

```
[공통 컨셉 붙여넣기]

슬라이드 역할: 표지.
현재 배치 유지: 상단 작은 부제 → 중앙 브랜드 제목 → 하단 「6조」.
넣을 텍스트만:
- 부제: 2035 미래 종교 디자인
- 한 줄 설명: 다종교가 함께 쓰는 영적 인프라
- 제목: 공명(共鳴) 스테이션
- 표어(작게): 「듣고 있습니다」 · 「말씀해 주십시오」
- 하단: 6조
시각: 흰 배경의 여백 많은 미니멀 표지. 제목 위(또는 근처)에 첨부 레퍼런스와 같은 **앰버 동심원 파동 1개**(얇은 선, 은은한 발광). 사람 얼굴·성물·복잡한 배경·다크 풀블리드 금지.
금지: 차콜/블랙 배경, 장식 이미지 여러 장, 네온, 로고 폭주.
```

## 슬라이드 02 — 문제 의식 (4칸 그리드)

**현재 배치:** 제목 + 본문 카드 4개(경청 희소 / 시설 문턱 / 매개의 역할 / 미래 종교의 과제).

```
[공통 컨셉 붙여넣기]

슬라이드 역할: 문제 의식 — 왜 이 모델인가.
현재 배치 유지: 상단 제목 1줄 + 2×2 카드 4장.
제목: 문제 의식 — 들어줄 자리가 없다
카드 4개 (각 카드 = 짧은 제목 1줄 + 본문 2줄):
1) 경청의 희소 — 연결은 늘었지만 / 평가 없이 끝까지 듣는 자리는 줄었다
2) 시설의 문턱 — 신앙 부재만이 아님 / 몸·말·민폐 감각이 발길을 막는다
3) 매개의 역할 — 숭배 대상이 아니라 / 돌봄을 잇는 길잡이어야 한다
4) 남은 과제 — 애도·소속·의미는 남는다 / 돌봄을 공간·기술로 구체화한다
시각: 카드마다 작은 단색 아이콘 1개만(이어폰X, 문턱, 다리/연결, 손바닥 돌봄). 사진 콜라주 금지.
톤: 진단이지 설교가 아님.
```

## 슬라이드 03 — 핵심 세 요소

**현재 배치:** 중앙 「미래 종교의 핵심 세 요소」 + 좌중우 1·2·3 카드.

```
[공통 컨셉 붙여넣기]

슬라이드 역할: 미래 종교의 핵심 세 요소.
현재 배치 유지: 가운데 짧은 타이틀 + 번호 달린 세로/가로 카드 3개.
가운데: 핵심 세 요소
카드:
1 Micro-Care — 교리 전파보다 / 미시적 경청과 위로
2 일상의 의례 — 복지관·구청·병원 로비에서 / 내려놓음이 의례가 된다
3 AI = Bridge — 사제·절대자 아님 / 듣고 짧게 위로한 뒤 사람에게 넘긴다
시각: 1·2·3 숫자만 강조. 카드 배경은 동일한 옅은 패널. 이미지 과다 금지.
```

**현재 배치:** 제목 + 「공명」설명 블록 + 「스테이션」설명 블록 + 표어.

```
[공통 컨셉 붙여넣기]

슬라이드 역할: 이름과 표어.
현재 배치 유지: 상단 제목 / 좌·우(또는 상·하) 두 블록 / 하단 표어 강조.
제목: 공명(共鳴) 스테이션
왼쪽(공명): 경청이 성립한 상태 / 평가·교정·개종 권유 없이 받아들여짐
오른쪽(스테이션): 일상의 내려놓음 거점 / 예배당에만 가지 않아도 된다
하단 표어(크게): 「듣고 있습니다」 · 「말씀해 주십시오」
보조 한 줄: 해결·설교가 아니라 현존과 초대
시각: 표어가 가장 크게. 파동 모티프는 아주 약하게만.
```

## 슬라이드 05 — 무게중심의 전환 (비교)

**현재 배치:** 제목 + 사회 조건 한 줄 + 「기존」vs「공명」대비 목록.

```
[공통 컨셉 붙여넣기]

슬라이드 역할: 2035 조건과 무게중심 전환.
현재 배치 유지: 상단 한 줄 전제 + 좌(기존) / 우(공명) 대비표.
상단 한 줄: 고립은 늘고, 들어줄 존재는 적다
대비 (각 행 짧게, 4행):
기존 → 공명
교리의 대규모 전파 → Micro-Care 경청·위로
집회장 중심의 성스러움 → 일상 부스의 내려놓음
먼 절대자만의 신 → 연대의 순간에의 현존
AI가 사제·신을 대체 → AI는 Bridge, 사람에게 연계
시각: 화살표 또는 Before/After 두 열. 글자 쪼개지지 않게 한 셀에 한 구절.
금지: 단어마다 줄바꿈된 파편 텍스트.
```

**현재 배치:** 제목 + 신성 재정의 + 공통/전통 레이어 + 거룩함.

```
[공통 컨셉 붙여넣기]

슬라이드 역할: 신성의 재정의와 다종교 인프라.
현재 배치 유지: 상단 정의 1블록 + 아래 레이어 2단(공통 / 전통).

상단(신성): 정답 강요가 아니라 / 취약함이 받아들여지는 연대의 순간

하단 한 줄: 거룩함 = 평가 없이 취약함을 말할 수 있음 / 심화 사목은 기존 공동체에
시각: 두 겹 레이어 다이어그램(아래 공통, 위 선택). 교단 로고 나열 금지.
```

**현재 배치:** 제목 + 파동/반응/의미/로고/한계 항목.

```
[공통 컨셉 붙여넣기]

슬라이드 역할: 상징 — 파동과 로고.
현재 배치 유지: 좌측(또는 중앙) 큰 파동 비주얼 1개 + 우측 짧은 불릿 3~4개.
제목: 상징 — 파동
불릿:
- 발화하면 완만히 반응한다 (과장 이퀄라이저 금지)
- 침묵하면 느리게 맥동한다 — 듣고 있음
- 말이 허공에 떨어지지 않음을 보여 준다
- 로고 = 파동과 여백의 단순화
하단 작게: 특정 성물은 기본 배치에서 뺀다 · 의자는 상징이 아님
시각: 화면 가득 장식 금지. 부드러운 원형 파동 히어로 1장만.
```

## 슬라이드 08 — 의례 흐름

**현재 배치:** 제목 + 긴 설명 문단 + 「이용 흐름」.

```
[공통 컨셉 붙여넣기]

슬라이드 역할: 의례 「내려놓음의 대화」.
현재 배치를 프로세스로 재정리: 상단 제목+시간 / 가로 4~5단계 플로우.
제목: 의례 — 내려놓음의 대화
시간: 약 5~8분
단계 (각 칸 = 동사 1개 + 부제 1줄):
1 앉다 — 문 닫고 숨 고르기
2 말하다 — 「말씀해 주십시오」(끊겨도 됨)
3 듣다 — 「듣고 있습니다」+ 짧은 침묵
4 위로 — 구체 반영 후 한 문장
5 마치다 — 원문 남기지 않음 (선택: 익명 연대 / 사람 연계)
금지: 긴 산문 문단. 앱 메뉴 스크린샷처럼 보이지 말 것.
시각: 단순한 화살표 프로세스. 사람 실루엣은 1명만.
```

## 슬라이드 10 — 성스러운 공간

**현재 배치:** 제목 + 침묵·앉을자리·빛 / 형태·입지 / AI 시각화.

```
[공통 컨셉 붙여넣기]

슬라이드 역할: 성스러운 공간 — 1인 방음 부스.
현재 배치 유지: 좌(또는 전면) 부스 이미지 1장 + 우 짧은 포인트.
제목: 말이 안전하게 떨어지는 방
포인트:
- 1인 방음 부스 (집회장 아님)
- 입지: 복지관·구청·병원 로비·종교시설 부속
- 조건: 침묵·시선 차단 · 앉을 자리(가구) · 느린 빛
- 성스러움 = 평가 없이 말할 수 있는 조건
하단: AI로 부스 외관·내부를 보여 주되, “교회 같다”가 아니라 “새지 않는 방”
시각: 미니멀 로비 속 부스 한 컷. 대형 성물·화려한 성전 이미지 금지.
```

## 슬라이드 11 — AI Bridge

**현재 배치:** 제목 + 하는 일 / 원칙 / 하지 않는 일.

```
[공통 컨셉 붙여넣기]

슬라이드 역할: AI의 Bridge 역할.
현재 배치 유지: 좌「한다」/ 우「하지 않는다」대비 + 상단 한 줄 원칙.
제목: AI = Bridge
상단 원칙: 신·사제가 아니다. 사람에게 넘긴다.
한다: 감정·사건·몸·관계를 반영하고 짧게 위로 / 위험·심화·요청 시 성직자·복지사·상담·핫라인 연계
하지 않는다: 교리 강의 · 확정 진단 · 숙제·점수화 · 구원자 행세 · 우상화된 가상 지도자
화면 고지(작게): 「몸의 돌봄은 사람 곁에서 이어질 수 있습니다」
시각: “다리/연결” 메타포는 추상적으로만. 인간형 신상·후광 AI 금지.
```

## 슬라이드 12 — 시나리오

**현재 배치:** 제목 + 정상 시나리오(박정자) + 위험 시 연계.

```
[공통 컨셉 붙여넣기]

슬라이드 역할: 설계가 작동하는 방식.
현재 배치 유지: 위 정상 플로우 / 아래 위험 예외 2단.
제목: 시나리오
위 — 박정자(78), 복지관 로비
짧은 비트만: 입장 → 「말씀해 주십시오」 → 아들·무릎·미안함 → 「듣고 있습니다」 → 짧은 위로 → 퇴장 (원문 없음)
```
