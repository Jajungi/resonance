# 부록 — 용어 안내 (2권)

| 이름 | 한 줄 |
|------|--------|
| 기본적 가치 | 성취·기억·무대·증명·종말로 차등화하지 않는 자리 |
| 형성적 가치 | 이야기·영웅·기사·높이로 밀고 나가는 지향의 층 |
| 파동 | 삶이 바깥으로 나가 남기는 영향 (별자리≠파동 전체) |
| 공명 경험 | 그 영향을 자기 안으로 이해한 층. 자동 성립하지 않음 |
| 기억 비조건 | 기억이 영원·가치·존재의 보증이 아님 |
| 사용 ≠ 인증 | 성검·별을 씀 ≠ 가치가 보증됨 |
| 한 걸음 | 별 소실 뒤에도 가치가 선행하고, 그다음에야 발이 옮아감 |
| 판결 정지 | 종말·여명의 카타르시스 앞에서도 삶 전체 선고를 서두르지 않음 |

금지: 별=가치 · 기억=존재 · 승리=구원 · 나는 진리 · 나는 별.
