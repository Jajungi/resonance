# A1 설정 변경표 (2026-10-04)

> 성격: 바뀌는 설정의 채택·폐기·미결 기록. 확정 교리 전문이 아님.
> 규칙: 설정이 또 바뀌면 새 날짜 파일을 추가한다. 이 파일은 덮어쓰지 않는다.

| 항목 | 이전(부록·구초안 등) | 이번 처리 |
|------|----------------------|-----------|
| 근본 | (암묵) 파동 존속이 성스러움·구원과 쉽게 연결 | **채택 확정:** 기본적 가치는 흔적과 독립. 파동으로 가치·구원·성스러움 자동 도출 금지 |
| 인간 가치의 의미 | 「그 자체로 가치」모호 | **기본적 가치**만 채택. 도덕적 무결점·우주적 목적 비채택. 행위·도덕 평가는 금지하지 않음 |
| 파동 남음 | 기억 없어도 세계에 실재·성스러움 근거 | **세 판단 층위** 분리. 강한 현재 실체 존속 미확정 |
| 개념 체계 | 혼용 | **세 층위** + **네 개념 측면**(단계·배타 분류 아님). 발화·전달도 영향 가능 |
| 말과 파동 | 말로 나와야 파동 | 말하지 못한 경험도 덜 실재하지 않음. 발화≠실재 조건 |
| 구원 | 구해지는 것은 파동 | **폐기.** 기존 구원 정의 **보존** + 가치 비부여 경계. 구원≠파동 존속 |
| 성스러움 | = 파동이 지워지지 않음 | **미결.** 존속만으로 선언 금지. 종교 전체 무효 아님 |
| 원음 | 점보다 앞선 확정 실재 | 사유 개념 유지. 존재론 **미결** |
| 내세 | 「다시 태어나지 않는다」식 부정 | **유보**(부정 아님). 실천은 고인 새 응답 **비전제** |
| 부록 처리 | — | 충돌 **3명제만** 비채택. 부록 전체 폐기 아님 |
