# 여기에 AI로 만든 이미지를 넣어 주세요

`make_pptx.py`를 다시 실행하면 PPT에 자동으로 들어갑니다.  
**한 장면에 여러 그림을 억지로 합치지 않습니다.** 파일만 넣으면 됩니다.

| 파일 이름 | 쓰이는 곳 |
|-----------|-----------|
| `logo.png` | 로고·상징 (계획안·최종) |
| `temple.png` | 성전/1인 부스 |
| `guide.png` | 가상 종교지도자 (Bridge) |
| `ritual_thumb.png` | 의례 영상 썸네일 |
| `music_cover.png` | 의례 음악 커버 |

권장: 흰/단색 배경, 가로·세로는 자유롭게 (스크립트가 칸에 맞춤).  
스크린샷은 `../screenshots/` (이미 있으면 중간·최종 시연에 사용).
