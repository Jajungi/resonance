# 인간과 종교 — 공명

**사이트:** https://jajungi.github.io/resonance/

2035년 조별 과제.  
**공명**은 관계·파동·공명 경험·구원을 말하는 종교의 이름이다.  
**공명 스테이션(부스)**은 그 종교를 한 번 수행하는 자리이지, 종교 자체도 교리의 출처도 아니다.

표어(실천): **듣고 있습니다** · **말씀해 주십시오**

## 핵심 한 줄

세계는 이미 관계로 되어 있고, 공명은 개인이 이해했다고 경험하는 일이며,  
부스는 그 경험을 판정하지 않고 수행하는 자리일 뿐이다.
