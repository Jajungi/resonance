# A부. 미래 종교를 생각할 때 고려할 점

*(근거: `자료/` 기독교 시리즈 대본 2·3·4편·부록 + 그 위에 세운 별도 정리. 교단 공식 교리 합의가 아님.)*

## A1. 문제 의식 — 왜 ‘미래 종교’를 다시 묻나

1. **설명의 독점 약화**  
   과학·의학·법률이 세계·몸·규범의 설명을 많이 가져갔다.  
   그런데 **의미·애도·경청·소속·죄책·복수심·용서**의 필요는 사라지지 않았다.

2. **들어줄 존재의 희소**  
   기술은 연결을 늘렸지만, 평가 없이 끝까지 들어 주는 자리는 줄었다.  
   고령·독거·돌봄 피로·야간 고립이 특히 가시적이다.

3. **제도 종교에 대한 피로와 균열**  
   자료가 비판하는 패턴:  
   - 「그냥 믿어」·두려움·기적으로만 JUMP  
   - 혀로만 사랑하면서 배타  
   - 글자·교리·권력이 사랑을 덮음  
   - 이성·청년 세대가 떠나기 쉬움  

4. **과제 맥락 (인간과 종교 2026-2)**  
   - 2035 새로운 공동체 (종교·문화·기술)  
   - 포함: 이름·세계관·상징·의례·공동체·윤리·성스러운 공간·AI 역할  
   - AI 활용: 로고·성전·의례 영상·음악·가상 종교지도자 등  
   - 평가: 종교학적 설득력 · AI 창의성 · 현실 활용성 · 완성도 · 팀웍

## A2. 자료가 말하는 ‘본래 겨냥’ (예수·사랑)

### A2.1 핵심 명제 (자료)
- **「서로 사랑하라」** — 처음부터 들은 계명으로 제시됨.  
- 황금률: 대접받고 싶은 대로 대접하라.  
- 한 줄 압축: **「칼은 칼로 돌아오고, 사랑은 사랑으로 돌아온다」**.  
- 목표는 믿기만이 아니라 **「날 따라 해봐요」** — 실천·모방.  
- “나를 안 믿어도, 내가 하는 일은 믿어라”(요한 인용 — 자료).

### A2.2 아가페의 실제 결 (자료)
- 조건·타이틀·편견 없이, **낮은 자·원수·죄인**까지.  
- 약자를 “네 믿음 탓”으로 몰지 않음. 세상은 부조리할 수 있음을 안다.  
- **분노와 용서는 한 짝**: 위선에는 단호, 뉘우침에는 품음.  
  용서 = “그럴 수 있지”가 아니라 **「다시는 그래선 안 된다」**는 무게.

### A2.3 율법·우상 (자료)
- 율법 폐기가 아니라 **본질 회복**.  
  안식일 등은 “더 사랑하고 행복하라고” 만든 규칙인데, 글자 숭배가 사랑을 혐오의 수단으로 바꿈.  
- **성경을 우상처럼** 대하는 이들에게 참뜻을 알리러 왔다는 독해.  
- 천국: 좌표가 아니라 **마음 안에**. 재앙에도 무너지지 않는 기준 = 사람이 고귀하다는 기준.

### A2.4 실제로 널리 쓰이는 문장들 (외부·전통 — 카피 참고용)

발표·UI에서 “AI 감성 문장” 대신 **이미 공동체 안에서 쓰인 말**을 빌릴 때:

| 출처·맥락 | 문장 (한국어에서 자주 쓰이는 형태) | 쓰임 주의 |
|-----------|-------------------------------------|-----------|
| 마태 11:28 (개신교·가톨릭 설교·찬양에서 매우 흔함) | 「수고하고 무거운 짐 진 자들아, 다 내게로 오라」 / 요약: 「무거운 짐, 혼자 지지 마십시오」 | 설교·회개 강요로 늘리지 말 것 |
| 요한 14:27 등 평화 기원 | 「평안을 너희에게 끼치노니」 → 현장: 「마음에 평화를」 | 가톨릭·개신교 위로에 한 문장 |
|  orthodoxy/가톨릭 동반 언어 | 「두려워하지 마십시오」 (성경·사목적 인사로 빈번) | 공포 마케팅으로 쓰지 말 것 |
| 불교 상담·법문에서 흔한 태도 | 「괴로움이 있습니다」 / 「있는 그대로」 | 긴 법문·수행 숙제로 비화 금지 |
| 한국어 돌봄·상담 현장 | 「듣고 있습니다」 / 「혼자 견디기 힘드셨겠습니다」 / 「그 밤이 길었겠습니다」 | 추상 ‘공간 메타포’보다 나음 |
| 애도·빈소에서 흔히 듣는 말 | 「말씀 다 못 하셔도 됩니다」 / 「천천히 하십시오」 | 서두르지 말라는 실제 예의 |

**피할 카피 (감 없고 AI스러운 패턴)**  
- “그 말씀을 여기 두셔도 됩니다”  
- “여기 머물러도 괜찮습니다”  
- “꺼낸 것만으로도 충분합니다”  
- “울림이 됩니다” / “결을 고르세요”  
→ 추상 공간·자기만족형 위로. **상대 말의 구체 내용**이 안 보임.

## A3. 왜 지금의 제도 종교처럼 굳었는가 (자료의 메커니즘)

| 메커니즘 | 요지 |
|----------|------|
| 글자의 ‘죽은’ 믿음 | 보이는 대로 율법·교리 대깨믿 → 본질 상실. ‘죽은 예수’ 숭배로 반복 |
| 우상 수요 | “이거 믿어라/절해라”가 형이상학보다 편함 |
| 언약의 덧칠 | LOVE and PEACE 위에 정복·멸망·‘군대의 신’ 서사가 덮임 |
| 우리 vs 다른 사람 | 선택받은 우리 / 멸망할 타자 프레임 |
| 재림·계시록 상상 | 박해의 분노 → 타자 멸망 환상. 이미 온 길을 글자로만 다시 기다림 |
| 번역·정경 | 인간이 고르고 옮김. 장치를 못 보면 근본주의로 굳음 |
| 이성 vs 영성 | 계몽이 폭력을 줄이기도, 신을 ‘죽이는’ 무기가 되기도. 교회는 부조리를 “어찌 알리오”로만 덮기도 |

**자료의 공백:** 콘스탄티누스·공의회 등 **제도사 타임라인**은 거의 없음. 발표에서 제도사를 말하려면 별도 사료 필요.

## A4. 미래 종교가 ‘좋으려면’ — 버려야 할 것 / 붙잡을 것

### A4.1 버릴 것
1. 글자가 사랑을 이기는 구조  
2. ‘우리만’의 구원·타자 멸망 서사  
3. 인물·제도·AI·건물의 **우상화**  
4. 혀만의 아가페 (말=사랑, 행동=배타)  
5. 두려움·기적만으로 JUMP (질문 금지)

### A4.2 붙잡을 핵 (한 문장)
> **칼의 논리를 끊고, 사랑의 논리를 삶으로 되갚는 공동의 습관.**

| 핵 | 의미 |
|----|------|
| 황금률 | 교리 시험보다 **관계의 최소 윤리** |
| 낮은 자 기준 | 브랜드·기적이 아니라 **가장 약한 쪽이 안전한가** |
| 산 믿음 | “지금 여기서라면 어떻게” — 업데이트되는 윤리 |
| 형제성 | 교단·민족·알고리즘 부족을 넘는 연습 |
| 비판+용서 | 위선에 단호 / 뉘우침에 품음 |

### A4.3 형태에 대한 바람 (구현명 없이)
1. 숭배 클럽보다 **돌봄·비폭력의 학교** (지표: 출석이 아니라 관계 복구·약자 보호)  
2. 경전은 우상이 아니라 **질문 가능한 대화 상대**  
3. 다원하되 느슨하지 않은 윤리 (낮은 자·비폭력·몸의 사랑)  
4. 권력·돈과 **어긋나는** 구조 (커질수록 위험)  
5. 신앙과 이성의 이혼 금지  
6. 구원·재림을 스펙터클만이 아니라 **안의 사건 + 밖의 삶**으로  

### A4.4 열린 질문
- 사랑을 제도·기술로 어떻게 구체화하나 (돌봄 노동, 난민, 혐오, AI)  
- 최소 공통 윤리만으로 되나, 신화·상징은 어디에  
- 폭력적 경전 구절 교육: 삭제 vs 비판적 문해  
- 살아 있는 길잡이가 사람/공동체/기술 어디에 실릴 때 다시 우상이 되나

# B부. 공명 스테이션 — 설계 전문

## B1. 한 줄 정의
**공명(共鳴) 스테이션**은 새 교단이 아니라, 2035년 여러 종교·지역사회가 함께 쓸 수 있는 **영적 인프라**다.  
키오스크(주) + 웹/모바일(부).  
표어 후보(개정 방향): 시적 ‘울림’보다 **「듣고 있습니다」 / 「말씀해 주십시오」** 쪽으로 현장감을 둘 것.  
(구: 「말해도 된다. 여기는 들어준다」「혼자 앓던 말이, 여기서 울린다」 — 발표용으로 쓸 수는 있으나 UI 본문은 더 건조·구체적으로.)

## B2. 미래 종교의 세 특성 (과제 발표용)
1. **돌봄 (Micro-Care)** — 교리 전파보다 미시적 경청·위로  
2. **일상의 의례** — 예배당만이 아니라 복지관·구청·병원 로비  
3. **AI = Bridge** — 신·사제 대체 아님. 위험·깊은 돌봄은 인간에게  

한 문장:  
미래 종교는 사람을 ‘믿게’ 만드는 기관이 아니라, **취약함을 평가 없이 들어 주는 공동의 인프라**여야 한다.

## B3. 세계관

| 이전 | 공명 |
|------|------|
| 진리·교리 전파 | Micro-Care |
| 예배당만이 성스러움 | 일상 부스에서 내려놓음이 의례 |
| 신은 저 너머 | 신은 **연대의 순간** |
| AI = 대체 사제/신 | AI = Bridge |

- **공통 레이어:** 부스·파동 UI·경청 윤리·휘발·위험 알림  
- **전통 레이어:** 가톨릭/개신교/불교/원불교/공통 — **위로 어휘만** 다름 (교리 시험·개종 금지)  
- **거룩함:** 기도문 암송이 아니라, **평가 없이 취약함을 소리 내는 행위** (+ 그 다음 층의 작은 실천·해악 앞 단호함)

## B4. 상징
- **잔잔한 파동:** 말하는 동안 반응, 침묵 때 느린 맥동. “말이 받아들여지고 있다”는 **시각 피드백** (과장된 이퀄라이저 X).  
- **빈 의자:** 특정 종교 성물 기본 비배치. 앉는 행위 = 받아들여질 자리.  
- 로고: AI로 파동·여백 마크 (사용자가 `assets/user/logo.png` 등).

## B5. 의례 — 「내려놓음의 대화」 전체 절차

목표 5~8분, 최대 12분.

| 단계 | 내용 | 시스템·톤 |
|------|------|-----------|
| ① 입장 | 방음, 빈 의자 | “앉아 주시면 시작합니다.” |
| ② 선택 | 전통 또는 공통 | 큰 버튼 5개 |
| ③ 초대 | 마음 걸린 말 | “말씀해 주십시오.” / 물어도 됨 |
| ④ 발화 | 끊겨도 됨 | STT, 파동, **평가 문장 금지** |
| ⑤ 침묵 | 「듣고 있습니다」 후 여백 | 해결책 금지 |
| ⑥ 위로 | 큰 자막 + 느린 TTS | **상대 말 반영** + 전통 짧은 문장 |
| ⑦ 연대(선택) | 익명 짧은 목소리 | “나만 아님” |
| ⑧ 작은 실천(선택) | 카드 1장, 건너뛰기 기본 | 안부 한 번 / 숨 세 번 / 되갚음 끊기 / 사람 안내 |
| ⑨ 사람 연결 | 위험·원함 | Bridge — **의례의 다음 문** |
| ⑩ 마침 | 휘발 | 게스트 삭제 / 멤버 요약만 동의 시 |

### B5.1 작은 실천 카드 (강요 금지)
- 한 마디: 바깥에서 안부 **한 번** (안 해도 됨)  
- 숨 고르기: 숨 세 번  
- 되갚음 끊기: 미운 마음에 **같은 말로 갚지 않기** 오늘 한 번  
- 사람 쪽: 복지·성직·상담 안내  

### B5.2 되갚음 끊기 침묵
미움·복수가 주제일 때:  
「그 마음은 이해합니다. **같은 아픔으로 갚을 필요는 없습니다.**」 + 짧은 침묵.

## B6. 공동체
- **기본:** 익명 연대 풀 (동의·성문 제거·기한부·태그 1개)  
- **선택 형제성:** 기존 성당/교회/사찰/복지 모임 안내; 또는 동의 시 느슨한 주제 방 (전화·출석·세력화 금지)

## B7. 윤리

| 원칙 | 내용 |
|------|------|
| 평가 금지 | 비난·성급한 긍정·개종·확정 진단 금지 |
| 해악 앞 단호함 | 취약함은 품되 타해·혐오·복수 미화·조장 금지 |
| 휘발 | 일반 세션 원문 삭제 |
| 위험 예외 | 최소 정보로 인간·핫라인 |
| 질문 허용 | 교리 시험이 아닌 한, 물어도 됨 |
| 규모 원칙 | 모으지 않는다 / 세력화 금지 / AI 숭배 금지 / 분산·감사 |

## B8. 성스러운 공간
- 1인 방음 부스, 휠체어, 큰 UI, 패닉 버튼  
- 설치: 노인정·복지관·구청·병원·종교시설 부속  
- 성스러움 = 침묵·차단·빈 의자·느린 빛  
- “교회 같다”가 아니라 **말이 새어 나가지 않는 방**

### B8.1 가정용·블루투스 스피커 (고려만, 미확정)
- 키오스크 = 원형, 집 = **연장** (거동·야간·수치심)  
- 폰+블루투스 스피커: 목소리 의례에 유리 / 가족 청취·성스러움 약화 리스크  
- 프로토타입 필수 아님. 후순위.

## B9. AI 역할
1. 1차 경청 — 감정·주제 반영, 짧은 위로  
2. Bridge — 위험·깊은 사목·자발 요청 → 인간  
3. 가상 지도자 = **매개 페르소나** (신 아님)  
4. “화면은 여기까지. **사람 곁에서** 이을 수 있습니다.”

## B10. 페르소나 시나리오 (박정자 78)
복지관 로비 → 공통 → 아들 전화·무릎·폐 될까 봐 → 침묵 → 반영 위로 → 익명 연대 → (선택) 안부 카드 → 퇴장·휘발.  
고위험·원한 변형은 구체화 문서 §8.

## B11. 기존 종교와의 관계
대체재 아님 · **연장재**. 교리 논쟁 없음. 깊은 사목은 인간.

## B12. 채널·메모리
게스트 휘발 / 멤버 요약만 MemoryCapsule / 키오스크 주·웹 부.

## B13. 프로토타입·일정
- 앱: `app/` · `npm run dev`  
- 9/17 계획안 · 10/1 제작 중 시연 · 10/8 완성  
- AI 산출물: 로고·성전·영상·음악·지도자 + 웹  

## B14. A부 정리와 공명의 정합·공백 (발표 방어용)

| A부의 기준 | 공명의 위치 |
|------------|-------------|
| 돌봄·비배타·반우상 AI | **강함** — 입구 설계 |
| 황금률·몸의 사랑 | **부분** — 작은 실천·사람 연결로 보강 |
| 칼/되갚음 | **얇게** — 되갚음 끊기 문장·카드 |
| 비판+용서 | **해악 층만** — 일상 감정은 평가 금지 유지 |
| 형제성 | 익명 + 선택 안내 |
| 질문·이성 | 고지에만 있음. 경전 문해 교육은 범위 밖 |
| 권력 | 규모 원칙으로 문서화. 실행·거버넌스는 과제 |

**한 줄 판정:** 공명은 A부가 말한 미래 종교의 **입구(경청 인프라)** 이고, 본진(비폭력 습관·형제성·몸의 사랑)은 **선택 층으로 얹은 상태**.

# C부. 카피·UI 원칙 (앱에 반영할 기준)

## C1. 작성 규칙
1. **먼저 상대 말을 되받는다.** (이름·사건·몸·관계)  
2. 그다음 짧은 안심·동행 — **공간 메타포 최소화**.  
3. 전통 모드는 **실제로 쓰이는 한 문장**을 최대 하나.  
4. “충분합니다/두셔도/머물러도/울림/결” **금지 목록**.  
5. 명령·숙제·점수화 금지. 실천 카드는 선택.

## C2. UI 본문 권장 문구 (개정)

| 위치 | 구(피함) | 신(권장) |
|------|----------|----------|
| 히어로 | 혼자 앓던 말이, 여기서 울립니다 | **듣고 있습니다.** / 또는 **말씀해 주십시오.** |
| 전통 선택 | 위로의 결을 고르세요 | **어떤 전통의 말로 듣길 원하십니까** (공통 가능) |
| 상태 | 천천히 말씀해 주세요 | **말씀해 주십시오** · 중간에 멈추셔도 됩니다 |
| 위기 | 평가하지 않습니다. 혼자 견디지 않으셔도… | **혼자가 아닙니다. 연결하겠습니다.** |
| 연대 | 울림이 되게 하기 | **비슷한 밤을 지낸 분의 말을 짧게 듣습니다** |

## C3. 전통별 위로 — 템플릿 방향
- **공통:** 구체 반영 + 「혼자 견디기 힘드셨겠습니다」  
- **가톨릭:** 반영 + 「마음에 평화를」 / 「두려워하지 마십시오」(과잉 사용 주의)  
- **개신교:** 반영 + 마태 11:28 요지 「무거운 짐, 혼자 지지 마십시오」  
- **불교:** 「괴로움이 있습니다」 / 「있는 그대로 듣겠습니다」  
- **원불교:** 일상·은혜를 **길게 설명하지 말고** “오늘의 힘듦을 있는 그대로 듣겠습니다”
